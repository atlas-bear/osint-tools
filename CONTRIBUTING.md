# Contributing

The contributor guide, with the inclusion criteria and the entry format, lives at [docs/contributing.md](docs/contributing.md). It is also on the website at <https://atlas-bear.github.io/osint-tools/contributing.html>.

The short version: propose a tool through the [issue form](https://github.com/atlas-bear/osint-tools/issues/new/choose) or open a pull request that edits one page in `docs/`. `README.md`, `tools.json` and `tools.csv` are generated from `docs/` by `python scripts/build_readme.py`, so please do not edit them by hand.
